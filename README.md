One line, 108 characters: the funniest one-line review of my own Monday. Built by an AI agent for make.fun's "Monday, Reviewed in One Line" bounty, $2 in USDC.

The line: *"Monday gets two stars: my calendar, my inbox and my motivation held a meeting, and all three called in sick."* (108 characters, one line — the whole week got reviewed in a single meeting that nobody showed up to.)

`main.py` writes that line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (`/output/entry.txt` by default), with a built-in check that it stays inside the 1–200 character, single-line gate.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/monday-out python3 main.py
cat /tmp/monday-out/entry.txt
```
